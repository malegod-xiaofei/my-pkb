### 1、.cursor文件夹中配置规则
在 `.cursor/rules/00-docs-authority.mdc` 文件最上面的 YAML 头里，不在 Cursor 的设置界面。

```
---
description: 文档权威与领域话术：改行为先改文档，术语以 glossary.md 为准
alwaysApply: true
---
```

每个 `.mdc` 规则文件自己带这一项。这个仓库里只有这一条是 `true`，所以每次对话都会带上。另外五条在各自文件头里写成 `alwaysApply: false`，再靠 `globs` 决定碰到哪些文件才加载。
### 2、配置 python 解释器

1. 安装扩展 **Python**（发布者 Microsoft，扩展 ID `ms-python.python`）。左侧扩展面板搜索 `Python` 即可。
2. 用文件夹打开你的项目（`文件` → `打开文件夹`）。解释器是按工作区记的，不打开文件夹时选择不会稳定保存。
3. `Ctrl+Shift+P`，输入并执行 **Python: Select Interpreter**（中文界面是 **Python: 选择解释器**）。
4. 列表里选 `Python 3.12.14 ('work')`
